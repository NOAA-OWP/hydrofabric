## Appendix A. Method Summary for Maintainers

Baseline family: intersect waterbody boundaries with flowpaths; choose the crossing nearest the oriented flowpath start as an inlet; generate outlet candidates from reaches with suitable boundary crossings; use flowpath_toid/downstream geometry to choose the downstream-side crossing; prefer candidates whose downstream neighbor leaves the waterbody; rank remaining candidates by drainage area, hydroseq, and length.


Alaska family: preserve all boundary crossings; order them along the flowpath; inspect geometry immediately before and after each crossing; classify true entry/exit transitions; keep the first valid inlet per reach; treat the final valid exit as an outlet candidate; traverse downstream TOID links to reject temporary exits that re-enter the waterbody; then select one final outlet per waterbody using topology/ranking.
