# Hydrofabric v3 methods documentation

Markdown conversion of the consolidated v0.3 Word draft. Source figures and tables retained. This is a standalone MkDocs documentation bundle intended for review before integration into the OWP repository.

## Local preview

```bash
python -m pip install mkdocs
mkdocs serve
```

Open the local address displayed by MkDocs. To build static HTML, run `mkdocs build`.

**Integration note:** If merging into an existing repository, copy the pages and assets into that repository's documentation tree and merge navigation into its existing `mkdocs.yml` rather than overwriting it.

**Source:** Hydrofabric_Waterbody_Hydrolocations_and_Hydraulic_Parameters_v3_Consolidated_v0.3.docx
